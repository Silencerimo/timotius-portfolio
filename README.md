# Timotius Kurniawan Portfolio

A modern, responsive personal portfolio website for Timotius Kurniawan, showcasing his expertise in governance, spatial planning, and data management.

## Features

- **Responsive Design**: Optimized for desktop and mobile devices
- **Clean Layout**: Professional color scheme with blue, gray, and white
- **Smooth Scrolling**: Navigation with smooth scroll behavior
- **Animations**: Subtle hover effects and fade-in animations
- **Sections**:
  - Hero/Landing Page
  - About
  - Skills
  - Projects
  - Publications/Reports
  - Contact

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript

## How to View

1. Open `index.html` in your web browser
2. Or serve locally using a web server:
   - Python 3: `python -m http.server 8000`
   - Node.js: `npx serve .`
   - Any static file server

## Customization

- Update personal information in `index.html`
- Modify styles in `styles.css`
- Add interactivity in `script.js`
- Replace placeholder image with actual photo
- Add real links for projects and publications
